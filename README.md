# Smart Timetable

## Project Title
Smart Timetable – Student College, Revision and Exam Planner

## Project Description
Smart Timetable is a student-focused web project designed to organize a student's
college timetable, revision schedule and exam preparation plan in one place.

The website provides:
- College weekly timetable
- Revision plan
- Exam preparation plan
- SEO Assignment section
- About section
- Responsive design for desktop and mobile devices

## Project Objective
The main objective of this project is to help students manage their academic
schedule in a simple and organized way.

The project also demonstrates SEO concepts required for the Digital Marketing
and Social Media course, including keyword research, content optimization,
SEO reporting and procedural SEO steps.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage
- Google Search Console
- Ubersuggest / Google Keyword Planner

## College Timetable
The timetable covers Monday to Saturday and includes:
- AI-Statistics
- Advanced Python
- Computer Graphics
- Data Structures and Algorithms
- Digital Marketing and Social Media
- OOPS with C++
- Project Based Learning
- Elective-I
- Laboratory sessions
- Recess periods

## Revision Plan
The website provides a weekly revision plan with dedicated study periods
for subjects such as:
- DSA
- OOPS with C++
- Advanced Python
- AI-Statistics
- Computer Graphics
- Digital Marketing
- Elective-I

## Exam Preparation Plan
The Exam Plan section provides a general preparation strategy covering:
- 4+ weeks before examination
- 3 weeks before examination
- 2 weeks before examination
- 1 week before examination
- Day before examination
- Exam morning

Actual examination dates are not included because they were not available
in the supplied college timetable.

4. Submit the website URL for indexing.

6. Select relevant primary, secondary and long-tail keywords.
7. Optimize the page title, meta description and headings.
8. Optimize the website content using relevant keywords.
9. Check mobile responsiveness.
10. Inspect the website URL in Google Search Console.
11. Record SEO performance data when available.
